# azhi_main

This is "Project Azhi", for now called "ChatSpaces" although the name and logo are working titles
and are subject to change.
This is a matrix client written in Dart, using the Flutter framework, and matrix-dart-sdk
Originally started as a university project, this is very much still in early stages of development.
Although it _works_, it's more than basic. It's a little more than an skeleton of an application.
Mostly because I haven't had much time to work on it during the past year or so that I've had this project.
